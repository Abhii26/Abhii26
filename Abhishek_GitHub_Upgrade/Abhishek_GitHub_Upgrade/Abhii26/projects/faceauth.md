# FaceAuth — Offline Face Authentication

A personal Flutter project for face enrollment and authentication without a network connection.

## What I built

- Offline face enrollment and authentication in Flutter and Dart.
- Embeddings stored locally in SQLite.
- Passive anti-spoofing and multi-frame liveness checks.
- Best-frame selection for the authentication flow.
